Cycle Settings

▼

What is a cycle?

One cycle is one automated run. The bot sends out your likes and messages, then goes quiet until the next scheduled time. Think of it as a single shift of activity.

Likes per cycle

How many profiles get swiped right each run. More likes means a bigger match queue coming in over time. Higher numbers work better when your match pool is fresh.

Messages per cycle

How many conversations get a message each run. Covers both replies to ongoing chats and first messages to new matches. The split is controlled by your Message Priority setting.

Likes per cycle Profiles swiped right each run
likes
Messages per cycle Conversations touched each run
msgs
Higher values increase efficiency but may trigger platform safety checks.

Who should I message?

▼

What does the slider do?

It controls who gets messaged first. People you're already talking to, or new matches you haven't spoken to yet. Slide left to focus on existing chats, slide right to reach out to more new people.

Which mode should I pick?

Nurture: Good chats already happening? This keeps replying to them so nobody gets left on read.
Balanced: No idea which to pick? Start here. Half replies, half new people.
Explore: Inbox gone quiet? This focuses on reaching out to matches you haven't spoken to yet.

What are the coloured boxes?

■
Blue: Someone already replied to you. The bot follows up to keep things going.
■
Green: A first message to someone you matched with but haven't spoken to yet.
■
Smart fill: If one pool runs dry, these messages go to whatever's available. Your daily limit never gets wasted.

Schedule

▼

Frequency

The interval between automated runs. Frequent runs (30-60m) are best for staying top-of-mind, while Relaxed runs (2-4h) look more natural.

Safety First

We recommend at least 60 minutes between runs to stay within platform safety boundaries. Excessive activity can be flagged.

Run Interval Frequency of automated activity

Interval is measured in minutes. 120 minutes = 2 hours.

Active Hours

▼

Restricted Window

The bot will only initiate runs during these hours. If a run is in progress when the window closes, it will finish its current task then sleep.

Natural Behavior

Using Active Hours makes your profile activity appear human. We recommend following your local timezone's normal waking hours.
